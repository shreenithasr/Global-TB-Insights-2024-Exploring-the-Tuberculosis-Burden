## Data Description

The original, uncleaned datasets contain WHO tuberculosis data across different countries, regions, and income groups over multiple years. The datasets include various TB-related indicators, which were identified and decoded using the reference tables provided in the **Codes** folder.

For this project, only data for **2024** is used for analysis.

**Original Data Source:** World Health Organization (WHO) – Global Health Observatory (GHO)  
**Source:** https://www.who.int/data/gho/data/themes/topics/topic-details/GHO/cases-and-deaths
