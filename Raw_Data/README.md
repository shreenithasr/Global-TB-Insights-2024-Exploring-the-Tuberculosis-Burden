# Raw Data

This folder contains the original, uncleaned WHO Tuberculosis datasets downloaded from the World Health Organization (WHO) Global Health Observatory (GHO) database.

## Dataset Source

**Source:** World Health Organization (WHO) Global Health Observatory (GHO)  
**Link:** https://www.who.int/data/gho/data/themes/topics/topic-details/GHO/cases-and-deaths

## Description

The datasets contain information on tuberculosis across different countries, regions, and World Bank income groups. They include data from multiple years and cover various TB-related indicators.

The original files contained indicator codes instead of descriptive names. I used the reference tables in the **Codes** folder to identify the dataset names and understand what each code represents.

With the help of these reference tables, I identified the relevant datasets for the project, including:

- TB incidence cases
- TB deaths
- TB cases among children aged 0–14 years
- HIV-associated TB cases
- Drug-resistant TB (MDR/RR-TB) cases
- TB treatment coverage

## Data Preparation

The datasets in this folder are kept in their original format without any changes. The reference tables in the **Codes** folder were used to decode the indicators and understand the data before selecting the relevant datasets.

The selected datasets were then used for data cleaning and transformation as part of the project.

Keeping the raw data separate helps preserve the original files and makes it easier to refer back to them during the analysis.
