# Data Pre-Processing Using Microsoft Excel and Power Query

## Description

The original WHO tuberculosis datasets were pre-processed to create a **cleaned master dataset** for the analysis of tuberculosis-related indicators for **2024**.

The data preparation process involved inspecting, cleaning, transforming, and consolidating the source datasets using **Microsoft Excel and Power Query**.

## Data Pre-Processing

The following steps were performed:

- Inspected the structure and contents of the source datasets.
- Reviewed the common columns across the datasets.
- Removed completely empty columns.
- Standardized column names and data types.
- Identified and handled missing values in **Parent Location** and **Parent Location Code**.
- Created conditional columns to appropriately handle missing parent-location information.
- Checked for duplicate records.
- Checked numerical fields for invalid or negative values.
- Verified the unique values in geographical and categorical fields.
- Appended the relevant tuberculosis datasets using **Power Query**.
- Created a consolidated **TB Master Dataset**.
- Filtered the master dataset to include **2024 data only**.
- Prepared the final cleaned master dataset.
